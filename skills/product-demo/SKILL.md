# Cut a product walkthrough

Open the resulting walkthrough in the [ClipReel video editor](https://www.clipreel.com/).

1. Name the product and the action the viewer should understand. Identify the exact takes, their desired order, and whether a screen contains material that should be excluded.
2. Import the chosen recordings. Ask `edit_by_prompt` to lead with the completed action, then show the steps and the result. Specify a target duration, which clicks or screen states have to stay, and whether to caption narration.
3. Review the preview next to the source. Check that the cursor stays visible on each click, the voice matches the screen, and the final product state has time to register. Make changes to the proposal or ask the user to approve it.
4. Apply the reviewed edit and export the requested aspect ratios. Give the same editable project link so the user can fix a caption without reuploading the source.

Example. “Use the dashboard, filter, and export recordings. Open with the finished report, keep the click that selects the filter, and end when the exported file opens. Make the cut 30 seconds and caption the narration.”
